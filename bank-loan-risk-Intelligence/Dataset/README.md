# Dataset folder

The CSV files here are **generated by the notebooks and are git-ignored** (see `.gitignore`): they are large, and they are derived from third-party data. Regenerate them by following `Documentation/dataset_guide.md` and then running the notebooks in `Python/` in order.

| File | Rows | Size | Written by | Used by |
|---|---:|---:|---|---|
| `raw/accepted_2007_to_2018Q4.csv` | 2,260,701 | about 1.5 GB | Kaggle download (not in the repo) | notebook 01 |
| `loans_clean.csv` | 150,000 | 39 MB | `Python/01_load_and_clean_lendingclub.ipynb` | notebook 02; SQL `stg_loans_clean` |
| `loans_model_ready.csv` | 150,000 | 21 MB | `Python/02_EDA_and_cleaning.ipynb` | notebook 03, 04 |
| `loans_woe_transformed.csv` | 150,000 | 27 MB | `Python/03_woe_iv_binning.ipynb` | notebook 04 |
| `loans_scored.csv` | 150,000 | 2.4 MB | `Python/04_scorecard_model_and_evaluation.ipynb` | SQL `stg_loans_scored` |

Column definitions are in `Documentation/data_dictionary.md`. The default rate in the 150,000-loan sample is 21.55%.
